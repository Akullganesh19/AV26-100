⚡ Bolt: Batch district stats queries

💡 What: Batched three separate scalar aggregate queries into a single database query using scalar subqueries.
🎯 Why: Reduces database roundtrips from 3 to 1 in the `get_district_stats` endpoint, resolving an N+1 query pattern.
📊 Impact: Decreases latency of the stats endpoint by eliminating multiple network trips.
