## 2026-09-28 — Eliminated Standalone Streamlit App (Integrated Diagnostics)
**Complexity found:** The entire `integrated_diagnostics` directory containing a standalone Streamlit application (`app.py`), duplicated dataset files, Jupyter notebooks (`.ipynb`), and a duplicated set of machine learning models (`.sav` artifacts), all structured outside the core backend FastAPI structure.
**Why it existed:** Historically, it seems this was built as a separate prototype, internship project, or standalone app (evidenced by the AICTE internship certificate and a completely separate Streamlit UI) that was later loosely integrated by pointing the backend configurations to its `Saved_Models` directory.
**Eliminated:** The entire `integrated_diagnostics` directory was deleted. The necessary clinical ML models (`.sav` files) were relocated directly into the backend directory structure (`backend/app/clinical_models/`). The redundant Streamlit UI, duplicate requirements, CSV datasets, training notebooks, and random certificates are completely removed.
**Net change:** Eliminated an entire standalone application layer, removed ~400 lines of UI code (`app.py`), and dropped multiple MBs of unused/duplicated CSVs, notebooks, and artifacts. Consolidates everything into the single FastAPI backend.
**Next target:** Evaluate if `FeatureBuilder` in `backend/app/ml/features.py` can be simplified by deriving features dynamically rather than through hardcoded mappings.
