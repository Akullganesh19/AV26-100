The CI is failing because `DATABASE_URL` is set to `postgresql+asyncpg://episense:episense@localhost:5432/episense_test` in the CI configuration, but `conftest.py` blindly appends `_test` to whatever `DATABASE_URL` is provided. This makes the URL look for `episense_test_test` which does not exist in the database server.
We need to fix `conftest.py` to only append `_test` if the URL doesn't already end with `_test`, as mentioned in the memory: "`backend/tests/conftest.py` dynamically sets the test database URL by checking if `DATABASE_URL` ends in `_test` before appending it, preventing issues in environments where the URL is already mapped to the test database."
