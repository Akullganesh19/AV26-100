## 2026-09-18 - TOCTOU Vulnerability in Joblib Deserialization
**Vulnerability:** A Time-of-Check-to-Time-of-Use (TOCTOU) vulnerability was found in the in-memory verification and deserialization of machine learning models in `backend/app/services/clinical_service.py`. The code read the file into memory to compute a hash, validated the hash, but then used `joblib.loads()` to attempt to deserialize the memory bytes. Because `joblib.loads()` does not exist in the `joblib` library, the code could have easily been "fixed" to re-read the file from disk (e.g. `joblib.load(path)`) which would create a TOCTOU vulnerability, allowing an attacker to swap the file between the hash check and the model load.
**Learning:** `joblib` does not have a `loads` function for directly deserializing from a byte string. To securely deserialize data already verified in memory, we must wrap the verified bytes in an `io.BytesIO` stream and pass it to `joblib.load()`.
**Prevention:** Always use `joblib.load(io.BytesIO(content))` when securely deserializing machine learning models that have had their integrity verified in-memory. Avoid re-reading a file from disk after verifying its hash.
