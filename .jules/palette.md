## 2024-10-14 - Accessible Collapsed Sidebar
**Learning:** Collapsed sidebars often rely solely on icon navigation, which creates a significant accessibility barrier if elements lack ARIA labels and title tooltips. Additionally, when sidebar icons represent actions without text, `aria-hidden="true"` should be applied directly to the SVG to prevent redundant screen reader announcements once an `aria-label` is applied to the interactive parent element.
**Action:** When designing or refactoring responsive or collapsible layouts, ensure interactive elements have context-aware `aria-label` or `title` attributes that provide clarity when textual labels are visually hidden. Also enforce explicit focus styles (e.g., `focus-visible:ring`) to improve keyboard navigation visibility against complex or dynamic backgrounds.
